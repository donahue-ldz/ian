# BYOM Default-Off Readiness v2

BYOM remains default-off.

BYOM exists to let advanced users configure a model provider later. It must not become Ian's identity, first-run experience, or a ChatGPT desktop skin. Demo Dialogue remains enough for the P0 local-first creature loop.

Readiness conditions:

- no API key is stored in config.toml.
- no provider is enabled without a locally stored key.
- no network request is made by default.
- bubble replies remain short and characterful.
- user can keep Ian fully usable without BYOM.
