# Settings Option Accessibility Audit

Current decision: local-first hardening, not a new product surface.

The settings surface must keep creature controls reachable without turning Ian into a configuration dashboard. The reduced motion option is a user-control affordance for comfort, and it must stay near movement intensity rather than becoming a separate advanced system.

Audit points:

- reduced motion is visible as a normal movement option.
- settings labels use user-facing language, not protocol names.
- future capabilities remain default-off.
- controls stay keyboard reachable and do not hide the core desktop creature.
