# Developer Rhythm Reprioritization

Recommendation: delay and hide by default.

Ian is a desktop creature first. Developer Rhythm should not compete with P0 life-like presence, touch reactions, resource polish, or local-first privacy work.

Decision:

- keep existing developer capability metadata as privacy copy and diagnostics only.
- do not add new user-visible Developer Rhythm behavior in P0.
- do not read code, diffs, terminal output, or key text.
- revisit in v0.2 only after Ian feels alive enough as a desktop companion.
