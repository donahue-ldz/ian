# Memory Export Low-Sensitive Audit

Current decision: memory export is a low-sensitive tag audit surface, not a user text export feature.

Export boundaries:

- memory export includes low-sensitive tags, status, and timestamps.
- low-sensitive tags are allowlisted.
- user free text, code, paths, HTML, private chat content, and terminal output are not exported.
- confirmed memories remain user-controlled and clearable.
- future long-term memory behavior remains default-off until a product review promotes it.
