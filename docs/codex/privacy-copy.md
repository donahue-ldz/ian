# 隐私文案

## 记忆

Ian 只会把低敏标签放进候选区。确认后才记住，本地保存，可删除。

候选不会自动变成长期记忆。未确认的候选不会进入对话上下文，也不会影响 Ian 的长期行为。

禁止使用“智能画像”“自动洞察”“全量上下文”等会误导用户的表述。记忆文案必须明确用户控制、本地优先和删除入口。

## 找回 Ian

找回快捷键默认关闭。开启后只监听一个找回 Ian 快捷键，不记录输入内容、按键序列或键盘节奏。

## 开发者节奏

开发者节奏能力默认关闭。文案必须说明读取范围和不会读取的内容，尤其是代码正文、diff、commit message 全文、终端全文、窗口标题和剪贴板。
