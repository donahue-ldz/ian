# v0.1 Baseline Readiness Map v2

Current decision: v0.1 baseline is architecture-first and default-off for future capabilities.

Ready or covered by tests:

- Tauri shell, Rust runtime, IanEvent, IanAction, IanState.
- Resource pack loader and built-in semantic coverage matrix.
- storage config, SQLite migrations, and repository skeletons.
- Security Gate, sanitizer, permission registry, and adapter sensitivity boundaries.
- Dialogue provider boundary with Demo Dialogue usable without network.

Skeleton / default-off:

- BYOM provider mode.
- reminders beyond gentle local timing.
- memory, social, plugin, resource import, sound pack, and developer rhythm.

Not product-ready:

- Feishu, Pet Visit, plugin execution, remote resource import, sound playback, code reading, terminal reading, screen OCR, and clipboard ingestion.
