# Ian 桌面端 Smoke 验收清单

本清单用于涉及桌面窗口、动画、拖动、找回、气泡、设置或资源包能力的 SDD。浏览器预览只能补充，不能替代真实 Tauri 桌面端验收。

## 启动

- [ ] 执行 `PATH=/opt/homebrew/bin:$PATH npm run desktop:tauri -- dev`。
- [ ] 通过标准：Tauri dev build 完成，`ian_desktop` 启动，启动日志没有 panic 或前端 fatal error。
- [ ] 失败处理：记录完整命令、退出码、首个错误和是否可复现。

## 基础存在感

- [ ] 桌面上能看到透明窗口里的 Ian。
- [ ] 通过标准：Ian 位于可见区域，窗口没有明显系统标题栏，点击命中区与宠物视觉位置一致。
- [ ] 失败处理：记录窗口位置、当前显示器数量和是否使用缩放。

## 点击与气泡

- [ ] 单击 Ian。
- [ ] 通过标准：出现短气泡，文本不超过 bubble-friendly 长度，Ian 播放轻量反馈动画。
- [ ] 失败处理：记录气泡是否被遮挡、是否有 console error。

## 拖动

- [ ] 按住 Ian 并拖到同一显示器另一处。
- [ ] 通过标准：桌面端拖动由 Tauri 原生拖动驱动；拖动期间不出现 React 手动 `setPosition` 造成的跳动；松手后停在释放位置。
- [ ] 失败处理：记录是否跳动、是否回弹、是否保存了错误位置。

## 位置恢复

- [ ] 拖动后退出并重新启动。
- [ ] 通过标准：Ian 恢复到上次保存的可见位置；如果上次位置越界，则回到安全区域。
- [ ] 失败处理：记录 `~/.ian/config.toml` 位置字段和实际窗口位置差异。

## 找回 Ian

- [ ] 在设置中点击“找回 Ian”。
- [ ] 通过标准：Ian 回到可见安全区域；如果本来可见，只给短回应，不移动到奇怪位置。
- [ ] 失败处理：记录触发前窗口位置、触发后窗口位置和 `system.shortcut_triggered` 是否仅包含 `find_ian`。

## 找回快捷键

- [ ] 默认状态确认快捷键关闭。
- [ ] 用户开启后按 `Cmd+Shift+I`。
- [ ] 通过标准：快捷键只触发找回，不记录按键文本或节奏；关闭后不再响应；冲突时设置面显示可理解提示。
- [ ] 失败处理：记录注册状态，不采集其他按键内容。

## 设置与隐私

- [ ] 打开设置，切换提醒、勿扰、宠物、大小、隐私说明和能力开关。
- [ ] 通过标准：设置面不遮挡主要交互；高敏能力默认关闭；记忆候选只显示低敏 tags；清空/删除入口可见。
- [ ] 失败处理：记录失败控件和是否影响 Ian 基础交互。

## 资源包切换

- [ ] 在设置中切换内置宠物。
- [ ] 通过标准：资源包切换后 sprite/animation 正常渲染，失败时回退默认资源包，不崩溃。
- [ ] 失败处理：记录资源包 id、manifest 错误和 fallback 结果。

## Post-0231 回归

- [ ] 切换“减少动画”。
- [ ] 通过标准：Ian 保留点击反馈，但不触发自主移动、pointer chase 或动态微特效。
- [ ] 开启勿扰后等待一次 tick。
- [ ] 通过标准：没有主动气泡、提醒、漫游或高能特效。
- [ ] 检查未来能力默认关闭。
- [ ] 通过标准：BYOM、Developer Rhythm、社交、插件、声音包、资源导入、Feishu、Pet Visit 不会默认联网或执行。

## 记录要求

每次执行后，把以下内容写入对应 SDD 的 `verification.md`：

- 执行日期。
- 命令和退出结果。
- 覆盖的 checklist 项。
- 失败项和跳过项。
- 剩余桌面风险。
