# Decisions: Resource Pack Visual Quality Pass

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 默认资源包需要独立质量验收，而不是只靠功能测试。 | 生命感高度依赖视觉连续性，资源问题会直接破坏产品感。 |
| 2026-05-21 | `rest` 使用独立 sprite 帧，不再复用 `idle` 帧。 | 0059 要求资源包层面状态可区分，不能只依赖外层 CSS 动效。 |
| 2026-05-21 | 资源质量清单保存在 SDD 目录，不引入产品路由。 | 质量验收需要可复用记录，但 P0 不需要用户可见的资源浏览器。 |
| 2026-05-21 | 截图预览通过本地 HTTP 服务打开 SDD preview，而不是 `file://`。 | Browser 策略阻止 file URL；localhost HTTP 是本地开发验证路径。 |
