# Spec: Resource Pack Visual Quality Pass

## 状态

已实现，待用户验收。

## 问题 / 目标

默认资源包决定用户对 Ian 的第一印象。0059 目标是对默认 Ian 资源包做一次视觉质量验收，确保基础动作、表情、尺寸、阴影和 fallback 一致。

## 当前产品阶段

Product Feel 体验优化。

## 产品范围

- 检查 idle、walk、run、happy、rest、sleep 等关键状态资源。
- 统一默认尺寸、锚点、阴影和透明边界。
- 保证缺失资源时 fallback 不破坏体验。
- 建立资源包质量检查清单，方便后续扩展。

## 明确不做什么

- 不制作大量新角色。
- 不引入皮肤市场。
- 不改变资源包协议的大方向。
- 不用临时 SVG 装饰替代真实 sprite 资源。

## 用户体验

用户看到的 Ian 在不同状态下比例稳定、动作可辨、没有跳帧、没有裁切、没有突然变形。资源缺失时也能优雅退回默认表现。

## 架构约束

- 资源包结构遵循既有 Resource Pack contract。
- React 负责加载和展示资源，不能把资源缺失变成行为逻辑。
- Rust Core 只输出状态和动作，不依赖具体图片文件名的 UI 细节。

## 数据 / 协议变化

优先不改协议。若需要新增 manifest 字段，必须向后兼容并提供默认值。

## 隐私与安全边界

资源包加载只读本地资源，不访问网络，不执行远程脚本。

## 验收标准

- [x] idle、walk、run、happy、rest、sleep 关键状态可区分。
- [x] 状态切换时没有明显尺寸跳变或锚点漂移。
- [x] 缺失资源有可用 fallback。
- [x] 资源包 manifest 可通过校验或 smoke 检查。
- [x] 截图覆盖主要状态和浅深背景。

## 验证方式

- 资源 manifest 校验。
- 前端资源加载测试。
- Browser / Tauri 截图覆盖主要状态。
