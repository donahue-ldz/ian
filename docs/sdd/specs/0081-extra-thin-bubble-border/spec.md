# 0081 Extra Thin Bubble Border

## 状态

已实现，待用户验收。

## 问题 / 目标

当前桌面宠物状态泡泡的云朵边框仍偏粗。用户希望气泡边框变成极细一些。

目标是把气泡主轮廓、顶部云朵瓣、尾部小泡泡和回复入口描边统一调细，同时保留现有云朵形状、位置、自适应大小和桌面宠物状态语义。

## 当前产品阶段

P0 / MVP + v0.1 Architecture Baseline。

## 产品范围

- 调细气泡相关描边。
- 保留淡色描边颜色。
- 保留 `pet-status` / `thought-cloud` 语义。
- 保留 `short` / `medium` / `long` / `input` 自适应尺寸。

## 明确不做什么

- 不改变 Rust Core 行为。
- 不改变气泡文本或 Demo Dialogue。
- 不新增外部依赖或素材。
- 不改变窗口尺寸、拖拽、设置面板或宠物资源包。

## 用户体验

- 气泡看起来更轻、更像桌面宠物状态提示。
- 边框不再有重漫画感。
- 回复按钮仍可用，但视觉干扰更低。

## 架构约束

- React 只负责气泡渲染。
- Rust Core 协议不变。
- 不新增权限、存储或外部输入。

## 数据 / 协议变化

无。

## 隐私与安全边界

无新增隐私或安全影响。

## 验收标准

- [x] 气泡主边框从 `3px` 调为极细描边。
- [x] 顶部云朵瓣和尾部小泡泡边框同步变细。
- [x] 回复按钮和输入框描边同步变细。
- [x] 描边颜色仍为淡色 `rgba(17, 17, 17, 0.64)`。
- [x] 气泡的桌面宠物状态语义、自适应尺寸和锚点保持不变。

- `npm run desktop:test -- Bubble.view.test.tsx`
- `npm run desktop:test`
- `npm run desktop:typecheck`
- `npm run desktop:build`
- 浏览器视觉检查并保存截图。
