# 0260 · Moment Desktop Acceptance Suite

## 问题 / 目标

Moment 的好坏必须在真实桌面端判断，浏览器测试不足以验证窗口位置、拖动、找回、动画节奏和惊喜感。本 SDD 建立 moment 桌面验收套件。

## 当前产品阶段

Desktop QA / Life Feel。

## 产品范围

- 定义 moment 桌面验收清单。
- 覆盖找回、鼠标好奇、拖动抱起、放下安顿、idle 惊喜、记忆回响。
- 记录主观体验观察，但验收标准必须客观。
- 不新增产品能力。

## 明确不做

- 不用浏览器验收替代桌面验收。
- 不要求一次性全自动化所有桌面交互。
- 不读取屏幕内容或用户隐私。

## 用户体验

后续每个 moment 上线前都能在真实桌面确认：看得到、不卡顿、不吵、不遮挡、不跑丢。

## 架构约束

- 桌面验收必须记录命令、环境、操作步骤、观察结果和剩余风险。
- 自动化不足时允许人工验收，但不能空缺。

## 数据 / 协议变化

不需要协议变化。

## 隐私与安全边界

验收不采集屏幕内容，不上传日志，不记录用户隐私。

## 验收标准

- [ ] 清单覆盖 0252-0259 的所有 moment。
- [ ] 每个 moment 有触发方法、预期动作、失败判定。
- [ ] 清单要求真实 Tauri 桌面壳。
- [ ] 记录 reduced motion、勿扰和设置打开时的降级验收。
- [ ] 后续 SDD 可引用该清单。

## 验证方式

- 文档自检。
- 执行一次真实 Tauri 桌面端 smoke。
- 将结果记录到 verification。
