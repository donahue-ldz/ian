# 0088 决策记录

## 2026-05-21

- 用户选择“小冒险家”方向，并明确希望动画数量多一些。
- 用户反馈黑灰剪影方向太黑、观感不好，因此角色从剪影线稿方向调整为原创像素风小冒险家。
- 角色采用原创“小冒险家 Ian”：像素块主体、浅色脸部、小背包、软围巾、发光探路棒；不逐像素复刻参考图，不做战斗角色。
- 黄色探路棒作为强色点，主体使用灰蓝、青色和浅色脸部，避免大面积黑色。
- 为了桌面端直接验收，当前前端默认资源包切到 `ian-adventurer`；配置层默认值暂不迁移，避免扩大本轮范围。
- 本 SDD 先建立大量动画目录，但第一批只保证现有语义动画可用，避免一次性扩大 Rust 行为协议。
- 额外动画 key 可以写入资源包作为素材储备，后续是否由 Rust Core 主动选择需要单独 SDD。
- 当前工作树混有多会话未提交改动，本轮只追加 0088 SDD 文档和后续 0088 范围内文件，不处理无关改动。
