# Spec: Soft Cloud Bubble Border

## 状态

已实现，待用户验收。

## 问题 / 目标

当前云朵气泡的纯黑 4px 描边过重，用户希望边框更淡一些。0078 目标是在保留云朵气泡轮廓、尾巴和可读性的前提下，把描边调轻，让它更柔和、不压过 Ian 本体。

## 当前产品阶段

P0 / MVP + v0.1 Architecture Baseline。

## 产品范围

- 将云朵气泡主描边从纯黑粗线调为更柔和的深灰半透明线。
- 将主体、云朵凸起和尾巴的边框宽度同步减轻。
- 保留白色气泡主体、自适应尺寸、两个尾巴圆点和输入控件。
- 更新浏览器截图作为视觉验收记录。

## 明确不做什么

- 不改变气泡形状结构和尺寸分档。
- 不改变 Ian 行为、文案、对话和输入逻辑。
- 不新增图片资源、主题系统或用户设置。

## 用户体验

气泡仍然是手绘云朵想法气泡，但线条更轻，不会显得笨重或抢占视觉注意力。

## 架构约束

- 仅修改 React/CSS 视觉层。
- Rust Core、IanEvent / IanAction、Storage 不变。
- 测试继续锁定视觉 token，避免后续回到纯黑粗线。

## 数据 / 协议变化

无协议和持久化变化。

## 隐私与安全边界

不读取任何新数据，不新增网络访问。

## 验收标准

- [x] 气泡描边颜色不再是 `#111` 纯黑。
- [x] 主体、云朵凸起和尾巴边框宽度不超过 3px。
- [x] 回复按钮和输入框仍有清晰边界但不使用重描边。
- [x] Browser smoke 截图记录轻描边效果。

## 验证方式

- `npm run desktop:test -- Bubble.view.test.tsx`
- `npm run desktop:test`
- `npm run desktop:typecheck`
- Browser smoke 截图。
