# 0074 拖动抱起交互

## 目标

用户拖动 Ian 时，Ian 应该像“被抱起来并放下”，而不是像普通窗口元素被拖动。拖动过程需要有轻微身体晃动、抱起反馈和放下反馈。

## 范围

- 拖动开始时播放高兴动画、低强度闪光特效和短中文气泡。
- 拖动过程中在 React 渲染层标记拖动状态，并播放轻微晃动动画。
- 拖动结束时移动到目标位置，显示放下反馈，并播放轻微脸红/缓冲特效。
- 保持位置保存路径不变。
- 真实 Tauri 桌面窗口中，拖动结束必须使用窗口屏幕坐标，不得把窗口内部指针坐标当成桌面坐标。
- 启动恢复位置必须保持窗口可见，不能恢复到屏幕外或左上角异常位置。

## 非目标

- 不新增复杂物理、惯性、碰撞或屏幕边缘互动。
- 不新增长期心情数值。
- 不实现撒泼、挣扎或拒绝被拖动。

## 验收标准

- 拖动开始和结束反馈明显不同。
- 拖动中的视觉状态可由 CSS 明确识别。
- 拖动不触发普通点击。
- 桌面模式拖动结束后，发送给 Rust Core 和保存到本地配置的是实际窗口坐标。
- 启动时保存位置越界会被夹到当前显示器可见范围内。
- Rust Core 负责决定拖动开始/结束反馈，React 只执行渲染和拖动手势。
- 前端和 Rust 测试覆盖关键行为。
