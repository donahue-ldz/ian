# 0074 实施计划

## 步骤

1. 扩展 `DragStart` 行为动作，加入气泡文案和轻量特效。
2. 扩展 `DragEnd` 行为动作，保留目标移动并加入放下后的轻量特效。
3. 在 `IanStage` 中增加渲染层拖动状态标记。
4. 在 CSS 中增加拖动时的轻微抱起晃动动画。
5. 修复桌面拖动坐标：桌面模式使用真实窗口坐标作为拖动结束事件和持久化坐标。
6. 修复启动恢复坐标：Rust 窗口初始化时将保存位置夹到显示器可见范围内，并同步回运行时状态。
7. 添加或更新测试。
8. 运行验证命令。

## 约束

- 不新增协议类型。
- 不改变拖动阈值。
- 不改变持久化接口。
- 不把 React 变成行为大脑；React 只负责真实窗口拖动坐标换算和渲染状态。
