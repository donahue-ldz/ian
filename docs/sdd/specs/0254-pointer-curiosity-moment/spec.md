# 0254 · Pointer Curiosity Moment

## 问题 / 目标

鼠标追逐如果太直接会像机械行为。本 SDD 设计“鼠标好奇瞬间”：靠近、观察、短追、退让、装作没事，形成更像生命体的反应。

## 当前产品阶段

v0.1.x / Life Feel。

## 产品范围

- 鼠标靠近时触发好奇 moment。
- 偶发短追逐，而不是每次都追。
- 追逐结束回到 idle 或轻气泡。
- 受冷却、设置、勿扰和 reduced motion 控制。

## 明确不做

- 不全局记录鼠标轨迹。
- 不持续追踪用户。
- 不在设置打开或输入气泡时触发。

## 用户体验

Ian 偶尔注意到鼠标，先探一下，再短追一下，或者追到一半假装没事。用户会觉得它在“好奇”，而不是被算法追踪。

## 架构约束

- 鼠标输入仍通过既有低敏 `mouse.near`、`mouse.leave`、`mouse.chase_candidate`。
- Rust Core 决定是否触发 moment。
- React 不独立随机。

## 数据 / 协议变化

优先复用已有鼠标事件和 `movement.move_to` / `animation.play` / `speech.show`。

## 隐私与安全边界

不保存鼠标轨迹，不记录全局行为，只处理当前低敏坐标事件。

## 验收标准

- [ ] 鼠标好奇 moment 不是每次靠近都触发。
- [ ] 设置打开、输入、拖动时不触发。
- [ ] 追逐距离和持续时间有上限。
- [ ] 冷却避免频繁打扰。
- [ ] 桌面端能观察到探头 / 短追 / 回 idle 的组合。

## 验证方式

- Rust 行为测试。
- 前端移动执行测试。
- 真实 Tauri 桌面端鼠标交互验收。
