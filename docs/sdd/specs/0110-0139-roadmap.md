# 0110-0139 SDD 拆分总览

## 拆分原则

- 延续 0090-0109，不修改前序 SDD。
- 0110-0114 聚焦 BYOM / Dialogue Provider 边界。
- 0115-0119 聚焦提醒、安静时段和本地诊断。
- 0120-0124 聚焦权限中心和 adapter 安全骨架。
- 0125-0130 聚焦 v0.2 Developer Rhythm 准备，默认关闭高敏能力。
- 0131-0139 聚焦资源包工具、桌面验收、可靠性、可访问性、发布和 v0.2 门禁。

## 建议节奏

1. 先执行 0110-0114，把 BYOM 和 Dialogue 安全边界搭稳，但默认仍保留 Demo Dialogue。
2. 再执行 0115-0119，把提醒、安静时段和本地诊断能力补齐。
3. 然后执行 0120-0130，建立权限中心和 Developer Rhythm skeleton，所有高敏能力默认关闭。
4. 最后执行 0131-0139，补资源包工具、桌面验收、可靠性、可访问性、生命周期、发布准备和 v0.2 门禁。
