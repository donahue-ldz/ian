# Decisions: Desktop Presence Chrome Reduction

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 默认桌面存在优先减少工具化 chrome，而不是新增视觉装饰。 | Ian 的核心验证是生命感，首屏控件过多会削弱陪伴对象的感知。 |
| 2026-05-21 | 设置入口改为低透明度图标按钮，面板打开时放在 Ian 本体外侧。 | 保留设置可达性，同时避免默认“设置”文字按钮和打开面板遮住 Ian。 |
| 2026-05-21 | 桌面窗口中设置面板改为向窗口内侧展开，浏览器预览保留外侧展开。 | Tauri 透明窗口宽度只有 260px，外侧展开会被窗口边界裁剪，导致点击后看起来没有弹出。 |
