# 0083 Bubble Text Full Center

## 状态

已实现，待用户验收。

## 问题 / 目标

用户澄清“居中”指文字在气泡内上下左右都居中。当前仅做了水平居中，回复按钮仍参与排版，导致文字在垂直方向偏上。

目标是让默认状态气泡中的文字在气泡内容区水平和垂直居中，同时保留回复入口、云朵形状、极细边框和自适应尺寸。

## 当前产品阶段

P0 / MVP + v0.1 Architecture Baseline。

## 产品范围

- 默认非输入气泡文字水平、垂直居中。
- 回复按钮脱离正文排版，避免挤压文字中心。
- 输入模式继续保留可用输入布局。

## 明确不做什么

- 不改变气泡文案、Rust Core 行为或协议。
- 不改变气泡边框粗细、锚点和尾泡形状。
- 不新增依赖。

## 验收标准

- [x] 默认气泡容器使用居中布局，让正文可上下左右居中。
- [x] `.ian-bubble-text` 水平、垂直居中且不再通过底部 margin 给回复按钮让位。
- [x] 回复按钮脱离正文排版，仍保持低干扰可点击。
- [x] 输入模式仍可显示输入框，不被默认居中规则破坏。

## 验证方式

- `npm run desktop:test -- Bubble.view.test.tsx`
- `npm run desktop:test`
- `npm run desktop:typecheck`
- `npm run desktop:build`
- 浏览器视觉检查并保存截图。
