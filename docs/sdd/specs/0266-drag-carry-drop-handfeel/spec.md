# 0266 · Drag Carry Drop Handfeel

## 问题 / 目标

Ian 需要能被自然拖动，并在被拖起和放下时有生命感。当前重点是修正拖动命中、位置偏移、释放反馈和动作衔接。

## 当前产品阶段

v0.1.x Life Feel / Direct Manipulation。

## 产品范围

- 优化 Ian 可拖动命中区域。
- 拖动中播放抱起 / 被拎着的状态或等价低动效反馈。
- 放下后播放安顿动作、短气泡或轻微弹性移动。
- 保证拖动位置持久化仍正确。

## 明确不做

- 不实现复杂物理系统。
- 不做窗口吸附管理器。
- 不实现跨应用拖放。
- 不读取目标窗口或桌面内容。

## 用户体验

用户应能直接拖起 Ian，Ian 不应偏离鼠标太远、不能突然跳到屏幕外。松手后 Ian 有短暂“落地安顿”的感觉。

## 架构约束

- 拖动事件进入 Core，Core 决定 carry / settle Moment。
- React 负责 pointer capture、窗口移动和动画执行。
- 位置持久化必须经过现有 storage / config 边界。

## 数据 / 协议变化

尽量复用现有 drag start / drag end 事件和 movement action。如需新增 carry state，必须由 Rust 协议定义。

## 隐私与安全边界

只处理 Ian 窗口拖动坐标，不读取桌面内容或其他窗口信息。

## 验收标准

- [ ] 用户能在真实桌面上拖动 Ian，拖动命中区稳定。
- [ ] 拖动时 Ian 不出现明显鼠标偏移、闪烁或跳屏。
- [ ] 放下后播放可感知但短暂的安顿反馈。
- [ ] 放下位置重启后仍能恢复或按现有规则处理。
- [ ] 拖动时其他 Moment 被抑制，避免动作冲突。

## 验证方式

- 前端 pointer capture / position 测试。
- Rust drag Moment 抑制测试。
- 真实 Tauri 桌面拖动、放下、重启恢复验收。
