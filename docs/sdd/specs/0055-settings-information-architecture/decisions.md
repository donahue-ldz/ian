# Decisions: Settings Information Architecture

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 设置按用户心智组织，技术开关后置。 | Product Feel 的目标是降低工具感，不让内部架构名词主导体验。 |
| 2026-05-21 | 设置面使用“性格 / 生活 / 打扰 / 隐私 / 高级”分组，隐私常显，高级折叠。 | 普通用户先看到陪伴体验相关项，同时隐私权限仍在一屏内可发现。 |
| 2026-05-21 | 技术能力标签改为用户可理解名称，例如“项目状态”“构建测试”“当前应用”。 | 避免主路径暴露 Git metadata、adapter、protocol 等内部词。 |
