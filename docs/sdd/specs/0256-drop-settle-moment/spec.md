# 0256 · Drop Settle Moment

## 问题 / 目标

用户放下 Ian 后，如果状态立刻回到普通 idle，会缺少生命感。本 SDD 增加“放下安顿瞬间”：放下后抖一抖、看一眼或短句回应。

## 当前产品阶段

v0.1.x / Life Feel。

## 产品范围

- `mouse.drag_end` 后触发短 settle moment。
- 根据拖动距离选择轻微或明显回应。
- 保存位置后再播放安顿动作。
- 冷却避免频繁拖动刷屏。

## 明确不做

- 不改变位置持久化语义。
- 不做长动画。
- 不做责备文案。

## 用户体验

用户把 Ian 放下时，它轻轻安顿一下，像“这里也行”。拖很短时只回 idle，拖很远时给一句短回应。

## 架构约束

- Rust Core 根据 drag_end 和状态决定 moment。
- React 执行动画 / 气泡。
- 位置保存必须可靠，不被视觉 moment 干扰。

## 数据 / 协议变化

优先复用已有 `mouse.drag_end`、`speech.show`、`animation.play` 和 `effect.play`。

## 隐私与安全边界

只使用拖动开始 / 结束位置和低敏距离，不记录用户桌面内容。

## 验收标准

- [ ] 放下后触发短安顿动作。
- [ ] 短距离拖动不会频繁打扰。
- [ ] 长距离拖动可出现短气泡。
- [ ] 位置保存先于或不受安顿动作影响。
- [ ] 文案不责备用户。

## 验证方式

- Rust drag_end 行为测试。
- 前端动作执行测试。
- 真实桌面拖动放下验收。
