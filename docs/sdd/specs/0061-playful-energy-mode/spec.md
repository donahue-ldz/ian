# Spec: Playful Energy Mode

## 状态

草稿，待确认。

## 问题 / 目标

Ian 需要一个明确的高能卖萌模式，用来承载满屏乱跑、撒娇反应和随机惊喜。0061 目标是先定义模式边界，避免把高能行为混进普通 idle roam，导致用户觉得失控。

## 产品范围

- 新增 playful energy mode 概念，可表现为 normal / playful / calm 等配置或内部策略。
- 高能行为默认低频，用户可在设置中关闭或降低。
- 高能模式必须受安静模式、拖拽、输入、睡眠和用户忙碌状态约束。
- 所有高能行为仍通过 `IanEvent` 和 `IanAction` 流转。

## 明确不做什么

- 不默认持续满屏乱跑。
- 不做完整 Mood / Bond 系统重写。
- 不做全局键鼠监听。
- 不让 React 自行决定何时高能。

## 用户体验

用户能感觉 Ian 偶尔会兴奋、撒娇、突然跑一圈，但这种兴奋是可爱的惊喜，不是持续打扰。

## 架构约束

- Rust Core 拥有 playful mode 的触发、冷却和退出策略。
- React 只展示设置入口和执行 action。
- 设置状态保存在本地配置，并进入 Security / Behavior policy 的统一判断。

## 数据 / 协议变化

可新增 `playful_energy` 配置字段，建议取值为 `off`、`low`、`normal`、`high`。旧配置缺失时默认 `normal` 或按现有行为退化。

## 隐私与安全边界

不新增外部数据读取。高能模式只使用 Ian 自身状态、本地时间、用户窗口内互动和本地设置。

## 验收标准

- [ ] 设置或本地配置中存在高能卖萌强度控制。
- [ ] `off` 时不会触发自发高能彩蛋。
- [ ] 安静模式、拖拽、气泡输入期间不触发高能行为。
- [ ] Rust Core 是触发策略来源。
- [ ] 测试覆盖默认值、关闭、高能强度和抢占保护。

## 验证方式

- Rust behavior / config tests。
- 前端设置测试。
- Browser smoke：切换高能强度并观察行为入口。
