# Decisions: Bubble Interaction Polish

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 气泡优先做短反馈和用户主动输入，不做聊天窗口。 | Ian 的桌面陪伴体验需要轻量存在，长对话会把产品拉向 ChatGPT skin。 |
| 2026-05-21 | 默认反馈气泡只展示短句和一个低干扰输入入口，输入框需用户主动展开。 | 避免默认形态像聊天窗口，同时保留键鼠可达的主动输入。 |
| 2026-05-21 | 输入 active 时，带 `state.sync` 且仍 active 的覆盖性 speech 会被前端忽略；输入结束后的回复允许替换。 | Core 已通过 `bubble.input_started` / `bubble.input_ended` 控制自主动作，前端还需避免旧输入态挡住用户自己的回复。 |
| 2026-05-21 | 气泡视觉改为更圆润的暖白半透明样式，输入入口和输入框同步圆角化。 | 用户反馈现有气泡过于方正、工具感强；本次只调整呈现，不改变气泡行为和协议。 |
