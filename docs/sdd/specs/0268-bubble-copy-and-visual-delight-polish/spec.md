# 0268 · Bubble Copy And Visual Delight Polish

## 问题 / 目标

Ian 的气泡和短文案会直接影响“可爱但不吵”的感受。当前需要统一 Moment 中的气泡视觉、文案长度、出现位置和退出时机，让反馈更柔和。

## 当前产品阶段

v0.1.x Life Feel / Bubble Polish。

## 产品范围

- 优化 Moment 相关气泡样式和短文案。
- 控制气泡宽度、圆角、阴影、箭头或贴近 Ian 的位置。
- 统一文案长度，避免像助手或通知。
- 处理气泡遮挡 Ian、遮挡用户工作区、和动画错位的问题。

## 明确不做

- 不做完整聊天 UI。
- 不接入 LLM 或网络能力。
- 不实现长文本对话。
- 不改 Ian 的核心身份为助手。

## 用户体验

气泡应像 Ian 的小情绪表达：短、轻、贴近角色，不方正僵硬，不挡太久，不抢用户注意力。

## 架构约束

- 文案由 Core / dialogue policy 或 Moment action 提供，React 负责呈现。
- React 不根据上下文自行编造 Moment 文案。
- 高敏外部文本不得进入气泡。

## 数据 / 协议变化

尽量复用 `speech.show` 或现有 bubble action。若需要增加 tone / duration / anchor 字段，必须由 Rust 协议定义。

## 隐私与安全边界

Moment 文案只能使用低敏状态和确认记忆标签，不展示原始隐私内容。

## 验收标准

- [ ] Moment 气泡文案短句化，不出现“AI 助手”语气。
- [ ] 气泡形态比当前更柔和，避免过于方正。
- [ ] 气泡位置不遮挡 Ian 主体关键区域，不明显溢出屏幕。
- [ ] 多个 Moment 连续触发时气泡不会叠加失控。
- [ ] reduced motion 或安静模式下气泡出现频率和时长可降级。

## 验证方式

- 前端气泡渲染测试。
- 文案快照或规则测试。
- 真实 Tauri 桌面观察找回、追随、拖动、放下、idle 气泡表现。
