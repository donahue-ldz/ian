# 0265 · Pointer Chase Curiosity Handfeel

## 问题 / 目标

Ian 偶尔追着鼠标或表现出好奇，是生命感的关键。但当前需要把触发时机、追随距离、速度、停止条件调得自然，避免机械、突兀或误触。

## 当前产品阶段

v0.1.x Life Feel / Pointer Interaction。

## 产品范围

- 优化鼠标靠近、离开、点击后的追随 / 好奇 Moment。
- 明确追随启动、追随中、停止、冷却的状态。
- 调整移动速度、曲线、最大追随距离和停止距离。
- 支持诊断模式下 100% 触发，正式体验仍遵守预算和冷却。

## 明确不做

- 不监听全局键盘。
- 不读取鼠标所在窗口内容。
- 不让 Ian 持续追逐打扰用户。
- 不把追鼠标做成游戏模式。

## 用户体验

当用户把鼠标移开或在 Ian 附近互动时，Ian 可以短暂追一下、探一下或靠近一下；追随应有“好奇”的感觉，随后自己停下。

## 架构约束

- 鼠标事件进入 Core 形成 Moment 决策。
- React 只上报 Ian 窗口相关或允许范围内的低敏鼠标信号。
- Moment 必须通过冷却和全局预算。

## 数据 / 协议变化

可能需要补充低敏 pointer 事件字段，例如相对位置、离开方向、距离等级；不得记录完整全局轨迹。

## 隐私与安全边界

不得记录用户完整鼠标轨迹，不读取鼠标下方内容，不上传交互日志。

## 验收标准

- [ ] 诊断模式可以稳定触发追随或好奇 Moment。
- [ ] 正式模式下追随受冷却和预算约束。
- [ ] Ian 追随距离和持续时间有限，不会长时间贴着鼠标。
- [ ] 鼠标快速离开时 Ian 不会跳屏或丢失。
- [ ] reduced motion 开启时追随降级为轻微转向、短气泡或低幅移动。

## 验证方式

- Rust Moment 触发和冷却测试。
- 前端 pointer 事件测试。
- 真实 Tauri 桌面用鼠标靠近、离开、点击 Ian 验收。
