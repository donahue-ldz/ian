# 0090-0109 SDD 拆分总览

## 拆分原则

- 先收口 0088 / 0089 留下的真实桌面验收和资源包体验。
- 再补 P0 到 v0.1.x 之间最影响“生命感”的基础体验。
- 架构继续面向未来，但用户可见能力保持克制。
- 不提前开放 Git、键盘节奏、飞书、Pet Visit、插件、多 Ian 等 v0.2+ 能力。

## 建议执行节奏

1. 先执行 0090-0092：把当前像素小冒险家和资源切换在真实桌面端收稳。
2. 再执行 0093-0096：补资源包选择、质量合同、恢复能力和窗口安全。
3. 然后执行 0097-0100：集中打磨生命感、鼠标反应、点击亲近和气泡策略。
4. 最后执行 0101-0109：补本地状态基础、轻量 mood / bond、温柔提醒、Demo Dialogue 和阶段验收门禁。
