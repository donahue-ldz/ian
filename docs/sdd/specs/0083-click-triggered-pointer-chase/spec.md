# 0083 点击随机触发追鼠标

## 目标

当用户用鼠标点击 Ian 后，再把鼠标从 Ian 身上移开时，Ian 朝当前鼠标位置追一小段，形成“摸它一下，它突然想追你”的调皮生命感。

该能力必须复用 0080 的追鼠标行为边界。当前为了体验验证，点击后首次鼠标移开时候选触发率临时调为 100%，但仍不能变成实时跟随或全局鼠标监听。

## 当前阶段

P0 / MVP + v0.1 Architecture Baseline。该能力属于 P0 生命感增强，只做小而可见的互动切片。

## 产品范围

- 用户点击 Ian 时，保留现有 `mouse.click` 反馈。
- 桌面模式下，点击后先布防；鼠标从 Ian 身上移开时读取一次当前鼠标坐标，并发送 `mouse.chase_candidate`。
- 如果 `pointerleave` 没有可靠触发，点击后短延迟兜底读取一次当前鼠标坐标并发送 `mouse.chase_candidate`。
- 是否真正追逐仍由 Rust Core 的 0080 追逐判定决定。
- 浏览器预览不读取桌面鼠标坐标。

## 明确不做

- 不绕过 Rust Core 追逐判定；点击后只发送候选，不保证每次都会实际移动。
- 不做实时贴身跟随。
- 不读取点击对象、窗口标题、屏幕内容、应用内容或鼠标轨迹历史。
- 不新增协议事件。
- 不绕过 0080 已有冷却、距离、安静模式、拖动和输入阻断。

## 用户体验

- 点击 Ian 后仍能看到原有摸摸/气泡反馈。
- 点击并移开鼠标后，如果 Rust Core 判定通过，Ian 会朝当前鼠标方向跑一小段，然后回到待机。
- 如果 Ian 正在拖动、输入、安静、冷却或鼠标距离不合适，则不会追逐。
- 行为表现为惊喜和调皮，而不是工具化跟随。

## 架构约束

- React 只负责点击后记录一次布防状态，并在鼠标离开 Ian 时采样一次桌面鼠标坐标并发送 `IanEvent`；若离开事件没有触发，则使用短延迟兜底采样。
- React 不决定追逐是否成立，不直接移动 Ian。
- Rust Core 继续通过 `IanEvent::MouseChaseCandidate` 和 `IanAction` 控制追逐行为。
- 不新增持久化字段。

## 数据 / 协议变化

无新增协议类型。继续使用：

- `IanEvent::MouseClick`
- `IanEvent::MouseChaseCandidate`

## 隐私与安全边界

- 只在点击 Ian 后、鼠标首次离开 Ian 时读取一次当前鼠标屏幕坐标。
- 不读取鼠标轨迹历史。
- 不读取窗口、屏幕、文本、文件或应用内容。
- 浏览器预览不读取桌面鼠标。

## 验收标准

- [x] 点击 Ian 时仍发送 `mouse.click`，保留原有点击反馈。
- [x] 桌面模式下点击 Ian 后只发送 `mouse.click`，不立即发送 `mouse.chase_candidate`。
- [x] 点击布防后，鼠标离开 Ian 时读取一次当前鼠标坐标并发送 `mouse.chase_candidate`。
- [x] 点击布防后，如果离开事件不触发，短延迟兜底也会读取一次当前鼠标坐标并发送 `mouse.chase_candidate`。
- [x] 鼠标离开后的候选触发率临时调为 100%，用于真实桌面体验验证。
- [x] 浏览器预览点击 Ian 时不读取桌面鼠标坐标，也不发送 `mouse.chase_candidate`。
- [x] Rust Core 不新增点击追逐专用分支，仍复用 0080 的 `MouseChaseCandidate` 判定。
- [x] 自动测试覆盖桌面点击 100% 发送候选和浏览器预览不发送候选。

## 验证方式

- 运行前端单元测试，覆盖点击触发追逐候选事件。
- 运行 Rust 行为测试，确认 0080 追逐判定仍通过。
- 运行 TypeScript 类型检查。
- 运行全量桌面前端测试和 Rust 测试，确认没有破坏现有行为。
