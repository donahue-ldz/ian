# Decisions: Playful Trigger Rules

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 第一版自发 trigger 只在 idle tick 的固定窗口内按 energy 间隔触发。 | 能稳定测试并避免持续随机打扰；更复杂的连续互动加权留到后续调参。 |
| 2026-05-21 | trigger reason 使用低敏字符串，例如 `idle_surprise`。 | 后续诊断可解释触发来源，同时不记录用户内容。 |
| 2026-05-21 | 高能彩蛋先以用户互动触发为主，自发触发为低频补充。 | 用户能主动获得惊喜，同时避免 Ian 在桌面上不可预测地打扰。 |
