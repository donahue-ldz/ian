# 0255 · Drag Carry Moment

## 问题 / 目标

拖动 Ian 目前更像移动窗口。这个 SDD 让拖动变成“抱起 Ian”的瞬间：拖动开始有轻反馈，拖动中状态稳定，用户能感觉是在移动一个小生命。

## 当前产品阶段

v0.1.x / Desktop Creature Usability。

## 产品范围

- 拖动开始进入 carry 视觉状态。
- 拖动中不触发自动游走、睡眠或追鼠标。
- 拖动时身体可以轻微缩放或切换动画。
- 桌面端仍走稳定原生拖动路径。

## 明确不做

- 不重新实现窗口拖动算法。
- 不增加跨屏自动漫游。
- 不读取屏幕内容。

## 用户体验

用户按住 Ian 时，它像被抱起：暂停乱动，轻微缩一下或切换表情。用户放下后再进入安顿 moment。

## 架构约束

- 拖动事件仍通过 `mouse.drag_start` / `mouse.drag_end`。
- Rust Core 负责拖动期间行为互斥。
- React 负责拖动视觉状态。

## 数据 / 协议变化

可复用 `playful.state`、`animation.play` 或轻量 appearance action。新增状态必须短期、可恢复。

## 隐私与安全边界

只处理 Ian 窗口内拖动事件，不采集全局鼠标轨迹。

## 验收标准

- [ ] 拖动开始 Ian 进入 carry 视觉状态。
- [ ] 拖动中自动游走、睡眠、追鼠标被抑制。
- [ ] 桌面窗口拖动稳定性不回退。
- [ ] 拖动结束后状态可恢复。
- [ ] 真实桌面端拖动验收通过。

## 验证方式

- Rust 互斥行为测试。
- 前端拖动视觉测试。
- 真实 Tauri 桌面端拖动验收。
