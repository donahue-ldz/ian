# 0140-0189 SDD 拆分总览

## 拆分原则

- 延续 0090-0139，不修改前序 SDD。
- 0140-0149 聚焦 v0.2 Developer Rhythm 的授权后低敏反应。
- 0150-0159 聚焦隐私、安全、脱敏和默认拒绝。
- 0160-0169 聚焦 Memory / Mood / Bond 的轻量本地演进。
- 0170-0179 聚焦 v0.3 Social Presence / Pet Visit 的默认关闭骨架。
- 0180-0189 聚焦 v1.0 Platform、资源生态、多实例、发布和 readiness map。
