# 0079 Cloud Bubble Window Safe Area

## 状态

已实现，待用户验收。

## 问题 / 目标

当前云朵气泡位于 Ian 头顶时，顶部云朵瓣会超出透明桌面窗口的可绘制区域，导致只显示下半部分。

目标是让点击气泡在桌面窗口内完整显示，包括顶部云朵瓣、文字、回复按钮和尾部小泡泡。

## 当前产品阶段

P0 / MVP + v0.1 Architecture Baseline。

## 产品范围

- 修复桌面透明窗口中云朵气泡顶部被裁切的问题。
- 保持当前云朵气泡的自适应文本宽度和较淡边框。
- 保持浏览器预览仍可用于检查 Ian 舞台。

## 明确不做什么

- 不改变 Demo Dialogue 生成逻辑。
- 不新增 Rust Core 行为。
- 不新增主动提醒、记忆、插件或开发者节奏能力。
- 不重新设计设置面板或宠物资源包。

## 用户体验

- 用户点击 Ian 后，完整云朵气泡显示在 Ian 头顶。
- 云朵顶部不能被桌面窗口上边界切掉。
- Ian 视觉位置仍接近窗口底部，避免为了气泡空间导致宠物明显悬空。

## 架构约束

- React 继续只负责渲染气泡和舞台布局。
- Rust Core 行为协议不变。
- Tauri 窗口只调整可绘制安全空间，不引入新权限或外部输入。

## 数据 / 协议变化

无。

## 隐私与安全边界

无新增外部输入、权限或持久化数据。

## 验收标准

- [x] 桌面窗口配置为气泡顶部预留足够高度，避免云朵瓣被裁切。
- [x] 桌面窗口渲染时 Ian 舞台靠近窗口底部，而不是在增高窗口内垂直居中悬空。
- [x] 浏览器预览仍保留居中布局，避免本地预览体验突然变化。
- [x] 气泡当前自适应宽度和淡边框规则保持不变。

## 验证方式

- `npm run desktop:test -- IanStage.test.tsx Bubble.view.test.tsx`
- `npm run desktop:test`
- `npm run desktop:typecheck`
- `npm run desktop:build`
- 浏览器视觉检查：点击 Ian 后确认云朵顶部完整可见。
