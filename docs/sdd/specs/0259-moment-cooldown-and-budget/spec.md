# 0259 · Moment Cooldown And Budget

## 问题 / 目标

Moment 如果没有总预算，容易从“惊喜”变成“打扰”。本 SDD 建立统一冷却和预算策略，控制 moment 频率、优先级和互斥。

## 当前产品阶段

v0.1.x / Life Feel Safety。

## 产品范围

- 定义全局 moment budget。
- 定义每类 moment 冷却。
- 定义勿扰、输入、拖动、设置打开、reduced motion 下的降级。
- 提供测试和诊断。

## 明确不做

- 不做复杂用户行为画像。
- 不把预算暴露成数值面板。
- 不绕过用户关闭开关。

## 用户体验

Ian 偶尔带来惊喜，但不会连续表演、刷气泡或频繁追鼠标。用户能把它调安静。

## 架构约束

- Budget 属于 Rust Core 行为策略。
- React 不维护频率策略。
- 所有 moment 必须申请预算。

## 数据 / 协议变化

优先使用内存态 budget。若需要持久化每日预算，只保存低敏计数和日期，不保存用户内容。

## 隐私与安全边界

预算只记录 moment 类型和计数，不记录用户内容、窗口内容或输入内容。

## 验收标准

- [ ] 每类 moment 有冷却。
- [ ] 全局预算能限制连续惊喜。
- [ ] 勿扰和 reduced motion 能降级。
- [ ] 设置打开、拖动、输入时 moment 被抑制。
- [ ] 测试覆盖预算耗尽和恢复。

## 验证方式

- Rust budget 测试。
- 设置 / reduced motion 测试。
- 桌面长时间观察。
