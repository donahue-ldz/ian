# Decisions: Touch And Affection Language

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 触摸反馈以动作和短句表达亲近，不暴露数值化养成。 | P0 / v0.1 的核心是生命感，数值面板会把体验推向管理工具。 |
| 2026-05-21 | 触摸语言先收敛为 Core 内部 `TouchReaction` 矩阵：单击、连点停顿、过度连点轻挪、拖拽开始、拖拽结束、双击跑动。 | 用代码显式记录反应矩阵，保持 React 只发送事件、执行 action。 |
| 2026-05-21 | 拖拽开始只给轻表情反馈，拖拽结束才给“放这里。”短句和位置落点。 | 避免拖拽过程中刷气泡，同时让拖拽也具备可区分触摸反馈。 |
