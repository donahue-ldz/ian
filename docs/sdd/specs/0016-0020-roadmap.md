## 拆分原则

- 0016-0020 进入 v0.2 Developer Rhythm，但仍坚持 local-first、显式授权、低敏摘要。
- Git、build/test、keyboard、active app 都必须先经过 Security Gate。
- Adapter 只生产 `IanEvent`，不直接控制动画、不直接写状态。
- 不读取代码正文、diff、终端全文、窗口标题、URL、屏幕 OCR 或按键内容。

- 0017 不能读取 stdout/stderr 全文。
- 0018 不能变成通知中心。

- 0020 只允许 app category，不允许窗口标题、URL、文件名或屏幕文字。
