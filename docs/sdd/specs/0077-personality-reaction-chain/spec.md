# 0077 个性反应链

## 目标

把 Ian 的单点反馈升级为短反应链，例如“看见用户靠近 -> 开心 -> 停一下 -> 小气泡”，让行为更像连续生命活动。

## 范围

- 为部分输入事件设计 2-4 步短反应链。
- 保持链路可中断，用户拖动或输入时优先。
- 反应链仍使用 Rust Core 统一决策。

## 非目标

- 不做完整行为树。
- 不做复杂 AI 规划。
- 不引入长期记忆。

## 验收标准

- [x] 至少一个事件能触发短反应链。
- [x] 反应链不会覆盖用户正在进行的交互。
- [x] 测试能证明动作顺序和中断保护。
- [x] 首个反应链不引入复杂行为树或 AI 规划。
