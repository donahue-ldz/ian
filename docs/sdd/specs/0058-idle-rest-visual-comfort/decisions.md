# Decisions: Idle Rest Visual Comfort

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 生命感优先通过微动作和状态过渡表达，而不是频繁位移。 | 长时间桌面陪伴需要舒适、克制和可持续。 |
| 2026-05-21 | 新增 `rest` 作为轻休息视觉状态，保留 `sleep` 作为闭眼睡眠状态。 | idle、rest、sleep 需要可区分，但 P0 不应引入完整 Mood / 作息系统。 |
| 2026-05-21 | time tick 使用 15 秒调度窗口，而不是只匹配整除秒。 | 桌面端每 15 秒发一次 tick；窗口判断能避免应用启动秒数导致 rest/sleep 永远错过。 |
| 2026-05-21 | quiet mode 和 `prefers-reduced-motion` 只降低动效强度，不移除 Ian 的存在感。 | 低打扰模式仍要保持陪伴感，同时尊重用户动效偏好。 |
