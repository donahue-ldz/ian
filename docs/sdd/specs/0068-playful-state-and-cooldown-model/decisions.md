# Decisions: Playful State And Cooldown Model

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-05-21 | 高能行为需要内部状态和冷却，但不做用户可见数值。 | 需要防失控和可解释性，同时保持 Ian 不是管理面板。 |
