# 0073 启动前 30 秒生命感

## 目标

Ian 启动后不应只是静态出现在桌面上，而要有一个短促、轻量、可忽略的“醒来”反馈，让用户感到 Ian 是刚刚来到桌面的生命体。

## 范围

本规格只处理 `app.started` 事件后的第一段反馈：

- 播放一次轻微高兴动画。
- 播放低强度闪光特效。
- 打开气泡并显示一句短中文文案。
- 不改变 Ian 的持久化位置。
- 不引入新的协议类型、长期记忆、心情系统或复杂调度。

## 非目标

- 不做首次安装引导。
- 不做长对话。
- 不做启动任务、提醒或主动生产力能力。
- 不做满屏游走。

## 验收标准

- `app.started` 产生可见的醒来反馈，而不是只有 idle。
- 启动反馈使用现有 `IanAction` 协议。
- 启动反馈不会触发位置迁移。
- 行为由 Rust Core 决策，React 只负责渲染动作。
- 相关 Rust 测试覆盖启动动作。
