# 0075 可见自动游走升级

## 目标

Ian 需要更明显地“自己在桌面上跑来跑去”，但仍然不能高频打扰用户。本规格将现有自动游走从小幅位移升级为更可感知的短路径游走。

## 范围

- 调整自动游走节奏和路径表达。
- 区分普通模式与活泼模式的游走幅度。
- 避免打断拖动、输入、睡眠、安静时段和忙碌应用场景。
- 保持位置边界约束。

## 非目标

- 不实现撒泼。
- 不实现窗口感知。
- 不实现跨屏巡游。

## 验收标准

- [x] Ian 在普通/活泼模式下能周期性出现可见游走。
- [x] 安静模式、安静时段、输入和拖动期间不自动游走。
- [x] 游走行为由 Rust Core 输出 `movement.move_to` 和 `animation.play` 动作。
- [x] 自动游走至少包含短路径移动和 `walk -> idle` 动画切换，而不是单点瞬移。
