# Spec: Presence Surface Polish

## 状态

已实现，待验收。

## 问题 / 目标

Ian 的桌面存在感不仅来自行为，也来自窗口表面质量。0035 目标是优化透明窗口、点击区域、阴影、缩放和视觉边界，让 Ian 更像住在桌面上，而不是一个粗糙浮窗。

## 当前产品阶段

v0.1.x Desktop UX。

## 产品范围

- 优化透明背景、阴影和 sprite 边缘。
- 明确可点击 / 可拖拽区域，不误伤气泡输入。
- 支持基础缩放或尺寸配置。
- 确认 always-on-top 与用户控制不冲突。

## 明确不做什么

- 不做复杂皮肤商城。
- 不做多窗口布局系统。
- 不做跨平台窗口深度适配。
- 不加入营销式 UI。

## 用户体验

Ian 在桌面上更自然，点击区域稳定，气泡不会被透明窗口或拖拽行为干扰。

## 架构约束

- React 负责渲染和交互表面。
- Rust Core 不处理视觉 CSS 细节。
- 可点击区域不得绕过已有 IanEvent 入口。

## 数据 / 协议变化

可扩展本地视觉配置，例如 scale。无需改变行为协议。

## 隐私与安全边界

只涉及 Ian 自身窗口和渲染，不读取外部屏幕内容。

## 验收标准

- [ ] 透明背景无明显矩形底色。
- [ ] 点击 Ian 和点击气泡输入不会互相干扰。
- [ ] 拖拽区域稳定，不导致误触发 click / double-click。
- [ ] 基础 scale 或尺寸设置可持久化或有明确默认。
- [ ] Playwright / Browser smoke 覆盖桌面表面关键状态。

## 验证方式

- Frontend interaction tests。
- Browser screenshot / smoke。
- Tauri 本地视觉 smoke。
