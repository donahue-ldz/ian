# 0076 撒泼卖萌触发规则

## 目标

Ian 可以偶尔撒泼卖萌，但必须像有分寸的小生命，而不是随机打扰用户。本规格只定义触发规则与保护边界。

## 范围

- 定义撒泼触发来源，例如连续忽略、活泼模式空闲、用户反复逗弄。
- 定义冷却时间和安静保护。
- 定义撒泼动作组合的最小协议表达。
- 设计可验收的诊断事件或测试方式。

## 非目标

- 不实现复杂情绪系统。
- 不做长期记忆。
- 不做强提醒或生产力催促。

## 验收标准

- [x] 撒泼不会在安静模式、安静时段、用户输入和拖动时触发。
- [x] 撒泼必须有冷却，不允许连续刷屏。
- [x] 行为由 Rust Core 决策。
- [x] 撒泼触发使用低敏诊断字段，不记录窗口内容、代码内容或用户隐私文本。
- [x] 撒泼复用现有 `speech.show`、`effect.play`、`animation.play`、`movement.move_to` 和 `playful.state` 协议。
