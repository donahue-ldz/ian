# 0080 偶尔追鼠标

## 目标

Ian 偶尔可以朝鼠标方向跑一小段，表现出“想追你一下”的调皮生命感，但不能变成实时跟随鼠标的工具行为。

## 当前阶段

P0 / MVP + v0.1 Architecture Baseline。该能力属于生命感增强，必须保持低频、可控、隐私默认安全。

## 产品范围

- 桌面模式下低频读取当前鼠标屏幕坐标。
- 将鼠标坐标作为 `IanEvent` 输入 Rust Core。
- Rust Core 判断是否触发追逐。
- 触发时 Ian 朝鼠标方向跑 1-2 段，然后回到 `idle`。
- 追逐必须有冷却。
- 安静模式、安静时段、气泡输入、拖动、跑动、玩闹冷却中不触发。

## 明确不做

- 不做实时贴身跟随。
- 不追踪点击、键盘、窗口标题、屏幕内容或应用内容。
- 不读取鼠标轨迹历史。
- 不跨屏长距离追逐。
- 不新增全局键鼠监听。

## 架构约束

- 外部鼠标坐标必须进入 Rust Core 表达为 `IanEvent`。
- React/Tauri 只负责低频采样和发送事件，不决定是否追。
- 追逐输出仍使用现有 `IanAction`：`playful.diagnostic`、`playful.state`、`animation.play`、`movement.move_to`、`effect.play`。
- 不新增持久化字段。

## 隐私与安全

- 只读取当前鼠标坐标 `x/y` 和当前时间。
- 不读取窗口、屏幕、文本、点击对象或应用内容。
- 诊断只记录低敏 key，如 `pointer_chase`、`triggered`、`blocked_distance`。

## 验收标准

- [x] 前端桌面模式低频发送 `mouse.chase_candidate`，浏览器预览不读取桌面鼠标。
- [x] Rust Core 在合适条件下返回追鼠标动作序列。
- [x] 鼠标距离过远、过近、安静模式、拖动、输入、跑动、冷却中不触发追逐。
- [x] 追逐动作不直接跳到鼠标点，而是朝鼠标方向靠近一小段。
- [x] 追逐触发后进入冷却，避免连续追。
- [x] 测试覆盖事件反序列化、权限、行为触发和阻断。
